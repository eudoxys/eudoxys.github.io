_Eudoxys Sciences release NERC Load Data Tool Marimo notebook_.

Eudoxys Sciences has released a [Marimo notebook](https://marimo.io/p/@lfenergy-fidopower/load-model-data?show-code=false) to navigate the load model data provided for the NERC Composite Load Model. The Load Model Data tool supports the NERC Composite Load Model as described in [Dynamic Load Modeling Technical Reference](https://www.nerc.com/globalassets/who-we-are/standing-committees/rstc/0-rstc-agenda-links/20251210_1_14_DRAFT_Dynamic-Load-Modeling-Technical-Reference_2025_8_19_LMWG_Approved_rev.pdf).

For more information see <a href="https://github.com/eudoxys/load_data_tool">Load Data Tool on GitHub</a>.
